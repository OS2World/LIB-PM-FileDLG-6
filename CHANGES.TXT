CHANGES.TXT -- LIB-PM-FileDLG-6 Change History
===============================================

Version 6.1 (2026-08-05)
-------------------------
32-bit OS/2 port -- all DLL source files ported from 16-bit OS/2 1.x / Microsoft C 6.00
to 32-bit OS/2 flat model, buildable with Open Watcom 2.0.

Build system:
  - Added Makefile.wat (project root) for Open Watcom 2.0; builds ERRMSG.DLL then
    FILEDLG.DLL, writing binaries to dll\ and import libraries to lib\.
  - Added sample\Makefile.wat for Open Watcom 2.0; builds OPENTEST.EXE and SAVETEST.EXE
    by importing FileOpenDlg / FileSaveDlg directly from FILEDLG.DLL by ordinal.
  - Replaced 16-bit .DEF module definition files with inline wlink export directives.

ERRMSG DLL (src\ERRMSG\):
  - errmsg.c: DosSemRequest / DosSemClear replaced with DosCreateMutexSem /
    DosRequestMutexSem / DosReleaseMutexSem / DosCloseMutexSem.
  - errmsg.c, errmsg.h, h\ERRMSG.H: removed cdecl / far / _loadds / _export / FAR
    modifiers; ErrMessageBox declared EXPENTRY throughout.

FILEDLG DLL (src\FILEDLG\):
  - opendlg.c: Ported all 16-bit APIs:
      DosQSysInfo            -> DosQuerySysInfo
      DosGetModHandle        -> DosQueryModuleHandle
      DosAllocSeg + MAKEP    -> DosAllocMem (PAG_COMMIT|PAG_READ|PAG_WRITE)
      DosFreeSeg(SELECTOROF) -> DosFreeMem
      DosSelectDisk          -> DosSetDefaultDisk
      DosQCurDisk            -> DosQueryCurrentDisk
      DosChDir               -> DosSetCurrentDir
      DosQCurDir             -> DosQueryCurrentDir
      WinQueryFocus(h, F)    -> WinQueryFocus(h)
      FILEFINDBUF            -> FILEFINDBUF3 (oNextEntryOffset traversal)
      DosFindFirst 6-arg     -> DosFindFirst 9-arg (FIL_STANDARD)
      NEAR / far / _loadds / SEL removed throughout
      DosOpen param 3: PUSHORT -> PULONG; param 8: ULONG -> PEAOP2
      HARDERROR_ENABLE / HARDERROR_DISABLE defined locally (not in OW headers)
  - finddlg.c: Same flat-model cleanup plus:
      DosSemSet/Clear/Wait   -> DosCreateEventSem / DosPostEventSem /
                                DosResetEventSem / DosWaitEventSem / DosCloseEventSem
      DosAllocSeg + MAKEP    -> DosAllocMem; DosFreeSeg -> DosFreeMem
      FILEFINDBUF            -> FILEFINDBUF3
      SearchThread signature changed to void (*)(void *) for _beginthread compatibility
  - savedlg.c: Same flat-model cleanup as opendlg.c.
  - parse.c: No API changes required.
  - static.c, buttons.c: No API changes required.

Warning fixes (zero warnings on clean build):
  - opendlg.c, finddlg.c: LOCAL usResult / rc changed USHORT -> SHORT to match
    signed LIT_NONE / LIT_MEMERROR / LIT_ERROR constants (W124).
  - finddlg.c: SearchThread parameter changed to void * with internal PDATA cast (W102).
  - parse.c: Trailing backslash in // comment converted to block comment (W123).

Version 6.0 (1990)
-------------------
Original release by Rick Yoder. Supports OS/2 1.2-1.3 (16-bit, Microsoft C 6.00).
Features: open/save/find-file dialogs, long filename support, multi-threaded find,
horizontal scroll bars, help button integration, comma-separated search patterns.
